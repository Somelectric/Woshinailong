减速 & 传动 Transmission

电机的"天然工作点"和任务的"需求点"天生不匹配——电机空转几千 rpm，任务只要几十 rpm； 电机扭矩几 mN·m，任务要几 N·m。传动机构用减速比 i 同时换算两者：ω₂ = ω₁/i，T₂ = T₁·i。 但"选哪种传动"从来不是查表题：齿轮中心距是死是活、要不要自锁、噪音与效率怎么权衡，直接决定你的底盘能不能装下、会不会啸叫。 本页先横向对比五条路线，再走完一道 i=20 的两级齿轮设计题。

齿轮 蜗轮蜗杆 行星轮系 同步带 链传动

怎么读这张表：紧凑高效但中心距死（中心距 = 模数×齿数和的一半，孔位偏了就顶死或啸叫）→ 齿轮，机器人关节与近距离减速的主力； 要大减速 + 自锁（升降断电不坠）→ 蜗杆，一级顶三级齿轮，代价是效率 40~90% 与发热； 同轴大减速、体积最小 → 行星，但装配条件（zp=(zr−zs)/2 须整数 + 均布）对自制不友好，俱乐部级别建议直接买成品模组； 中心距灵活、安静免润滑 → 同步带，3D 打印机 X/Y 就是答案；大中心距 + 大扭矩 → 链，但会伸长、有冲击噪音。 注意最后两列：同步带与链断电都不自锁——想让机器人停在坡上，还得靠蜗杆或刹车。
例题

一道两级齿轮减速设计题：i = 20

需求：底盘电机 3000 rpm 减到轮上 150 rpm（i = 20），输出扭矩要尽量大、结构要装得进底盘。

  1. 判单级i=20 超限——单级直齿轮实用 ≤6（齿数差太大 → 小轮齿数被削、大轮体积爆炸），必须拆级或换原理
  2. 选架构两级直齿轮 4×5；或一级行星（~6 内）多级；或蜗杆一级到位但 η≈40% 发热——底盘要效率，选两级直齿轮
  3. 定齿数模数 m=1（打印齿轮 m≥1.5）→ 第一级 z₁=20, z₂=80（i=4）＋第二级 z₃=20, z₄=100（i=5），验算 4×5 = 20 ✓
  4. 排孔中心距 a = m(z₁+z₂)/2 逐级计算，全部轴孔在同一块板一次钻孔，公差 ±0.05 mm
齿轮三定律
i = z₂/z₁　·　ω₂ = ω₁ / i　·　T₂ = T₁ · i × η
传动比由齿数比决定（与直径比等价：节圆直径 = 模数 × 齿数）； 转速按 1/i 降，扭矩按 i 升（乘效率 η，单级齿轮约 0.97）。 外啮合两轮转向相反；中心距 = (z₁+z₂)·m/2，装反了齿就顶死。
为什么是它 vs 其他：齿轮的护城河是单级效率 ~97% + 传动比恒定 + 承载强——同步带会松弛、链会伸长，只有齿轮的传动比是几何刻死的； 它的死穴同样出名：中心距不灵活（两轴孔距离必须精确到 ±0.05 mm，孔位钻偏 = 啸叫或顶死）且单级传动比超 6 就不经济。 所以近距离、要精度、要效率 → 齿轮；两轴离得远 → 同步带/链；要自锁 → 蜗杆。电机到轮边那几十毫米，几乎总是齿轮的地盘。

优点

  • 传动比精确、恒定
  • 效率高（单级 ~97%）
  • 承载强、寿命长

缺点

  • 需要润滑
  • 高速噪音
  • 远距离传动结构变大

适用

  • 机器人关节减速
  • 变速箱
  • 打印件也能做（低载）
自锁：只许进不许退
i = z₂ / z₁　　导程角 γ < 当量摩擦角 φv → 自锁
单头蜗杆（z₁=1）转一整圈，蜗轮只前进一个齿——单级就能做到 i = 40~80。 更妙的是反向自锁：蜗杆能推动蜗轮，蜗轮却推不动蜗杆——升降机构断电也不会倒转坠落。 代价是滑动摩擦大：效率仅 50~90%，发热明显。
为什么是它 vs 其他：四条路线里只有蜗杆能"一级顶三级"（i=40 对应齿轮要三级 4×5×2）并同时白送自锁—— 断电时负载推不动蜗杆，升降机构不需要任何刹车。这笔账要算清楚再选：若你的机构每个循环都在升降，η≈40% 意味着一半以上电能变热， 电机被迫加大一档；若只在终点保持位置（低占空比），发热可控，蜗杆几乎是不二之选。要效率选齿轮/行星，要"停得住"选蜗杆。

优点

  • 单级大减速比（30~80）
  • 结构紧凑、轴交角 90°
  • 可自锁（防倒转）

缺点

  • 摩擦损失大（η 50~90%）
  • 发热
  • 铜蜗轮成本高

适用

  • 升降机构（自锁防坠）
  • 阀门驱动
  • 绞盘/卷扬
Willis 公式（内齿圈固定：太阳轮输入 → 系杆输出）
i = 1 + zr / zs
行星轮"自转 + 公转"，妙在输入输出同轴、多齿同时受力——同样的减速比，体积比普通齿轮系小得多， 承载高得多。这是电动车减速箱、机器人关节模组（RV/谐波之前的入门级）的核心。 装配条件：zp = (zr − zs)/2 必须是整数（判定框会实时检查）。
为什么是它 vs 其他：行星的三张牌——同轴（输入输出一条线，底盘轴系布置不用拐弯）、多齿均载（同样的模数承载翻几倍）、 紧凑（大减速藏在轮系内部不外扩）。普通齿轮系要三级才到 i=100，行星两级就够且体积小一半。 但对俱乐部自制而言它是最难自己做的：装配条件、三个行星轮的均布相位、内齿圈加工，三者任一出错整套卡死—— 实际打法是买成品行星减速箱，把设计精力留给输出端。

优点

  • 同轴输入输出
  • 紧凑、比功率大
  • 多齿受力，承载高

缺点

  • 设计复杂（装配条件）
  • 加工精度要求高
  • 内齿圈成本

适用

  • 电动车减速箱
  • 机器人关节模组
  • 风电齿轮箱
同步带 vs 链：都要张紧，性格相反
i = z₂/z₁ = n₁/n₂　　带速 v = ω₁·r₁（两轮表面线速度相同）
同步带 vs 链：两者都靠"齿啮合"保无滑差、都需要张紧，但同步带安静、免润滑，链能传更大扭矩—— 比赛分拣机器人负载轻，同步带足矣；重载大跨距（底盘传动轴到轮）才轮到链。 两者的断电都不自锁：带会被负载反向拖动（皮带拉伸弹回）、链会倒转，要停在坡上得靠蜗杆或刹车——这是 6.1 表里"自锁性"一行为空的原因。 另一个差异藏在维护曲线里：带是"_install 后缓慢松弛"（调一次张紧就好），链是"持续磨损伸长"（要经常补调或换）。

优点

  • 远距离传动轻巧
  • 齿啮合无滑差
  • 无需润滑、安静

缺点

  • 长期张紧会松弛
  • 抗冲击差
  • 寿命有限（张紧件）

适用

  • 3D 打印机 X/Y（GT2）
  • 发动机正时
  • 轻载长行程直线
链的独门优势与代价
i = n₁/n₂ = z₂/z₁　　多边形效应：链节绕轮成多边形 → 瞬时传动比波动
为什么还用链：金属链的扭矩容量与中心距自由度是同步带给不了的——大跨距重载（叉车、收割机、摩托车）几乎全是链的领地， 且它不怕油污高温。代价：多边形效应使瞬时传动比周期波动（冲击噪音的来源）、需要润滑、磨损后持续伸长（要张紧轮补偿）。 俱乐部场景的判断很简单：负载轻 + 要安静 → 同步带；要传动轴跨整个底盘传大扭矩 → 链。两者断电都不自锁。

优点

  • 承载能力大
  • 无滑差
  • 远距离效率高

缺点

  • 需要润滑
  • 噪音与多边形效应
  • 链节磨损伸长

适用

  • 自行车/摩托车
  • 叉车提升
  • 农业机械（收割机）

一个真实的选型题：电机直驱 vs 减速驱动

直流电机空载转速动辄 3000–10000 rpm、扭矩只有几十 mN·m；机器人轮子要的是 100–300 rpm、零点几 N·m。 缺口靠减速箱填——i = 30 的行星减速箱把 6000 rpm/20 mN·m 变成 200 rpm/0.6 N·m（理想）。

减速的代价与回报
ω₂ = ω₁ / i　　T₂ = T₁ · i · η
回报：扭矩放大 i 倍；速度落到可控区间；反驱动也变难（大 i 接近"断开"负载反冲）。
代价：齿隙（backlash，换向时有空程）、效率损失、体积重量、噪音。
选型经验：底盘轮组 i ≈ 10–40（直流减速电机一站式买齐）；关节臂 i ≈ 50–200（多级行星/蜗杆）； 需要反向可驱动（腿式机器人）时 i 要小，否则落地冲击全怼进齿轮。
方案典型组成优点短板
步进直驱（往届赛车用法） 42 步进 + 麦轮，无减速器 结构最简、开环定位、低速扭矩尚可 高速掉步、共振区、效率低
直流减速 + 编码器（当前主流） N20/380 电机 + 行星/齿轮箱 + 磁编码器 闭环、高扭矩密度、PID 可调速度环 需要调参、多一根编码器线
无刷 + 减速 云台电机/电动工具电机 + ESC/FOC 效率最高、无刷磨损、安静 驱动复杂、成本高
别忘了悬挂
现在的轮组普遍做成"电机 + 弹簧悬挂 + 轮"一体化模块：弹簧把轮压向地面， 场地不平时轮子上下浮动、始终保持接触——不打滑，编码器读数才可信，闭环才成立。 这本质上是用机构（弹性）给控制兜底，和上一页"柔顺爪"是同一设计哲学。
