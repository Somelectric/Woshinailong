轨迹合成 Complex Motion

什么时候需要这种运动？ 末端要走一条无法用单自由度机构生成的 2D 曲线—— 一行字、一个不规则轮廓、或要绕障的轨迹。两条思路： ① 加自由度（五杆、串联臂）；② 轨迹刻进几何（多杆组合、凸轮连杆、并联机构）。 这一页不止讲原理——7.1~7.4 给你"给定曲线 → 怎么设计出机构"的完整方法论。

选路线：轨迹简单重复、要超高节拍 → 凸轮+连杆（工业自动机）； 要可编程、中等节拍 → 五杆或串联臂（我们的选择）； 超高速拾放 → Delta 并联。六杆适合"一条曲线用了几十年"的固定工序（缝纫机）。

为什么是 2 自由度
F = 3n − 2PL = 3 × 4 − 2 × 5 = 2
五杆 = 四杆再加一根杆一个铰。F=2 意味着必须两个原动件同时输入，末端 C 的轨迹 由两输入的频比 ω₁:ω₂ 和相位差 φ共同调制——不同步时走出类 Lissajous 曲线； 严格同步（ω₁=ω₂）时退化为一个"刚性四边形"摆动。这就是"自由度买轨迹自由"。

优点

  • 2 自由度 → 末端轨迹是真正的 2D 曲线
  • 闭环连杆：刚性远高于悬臂串联臂
  • 两原动件都接地 → 电机不做悬臂负载

缺点

  • 需要 2 电机严格协同
  • 工作空间形状复杂（两个圆环的交集）
  • 轨迹规划比串联臂难（无解析逆解直觉）

适用

  • 提速类拾放（频比可调）
  • 印花、点胶、绣花走线
  • 并联机械手的入门结构
六杆 = 四杆 + 二连杆组（Dyad）
在四杆的连杆上再挂一组"杆 + 杆"，末端点走连杆曲线的连杆曲线—— 曲线族一下子丰富起来，还能造出带近似停歇段（Dwell）和平直段（近似直线）的轨迹。 F = 3×5 − 2×7 = 1，仍然是单电机机构——复杂轨迹不一定要多电机。 经典 Watt / Stephenson 型是缝纫机挑线、印刷机送纸的主力。

优点

  • 比四杆丰富得多的曲线族
  • 可设计停歇段 / 近似直线段
  • 仍是 1 自由度，单电机

缺点

  • 杆多 → 累积误差与间隙
  • 动平衡难，高速振动
  • 综合（设计）复杂

适用

  • 缝纫机挑线机构
  • 印刷/包装机送纸翻盖
  • 近似直线搬运
轨迹刻进几何
凸轮把"随时间变化的位置规律"固化在廓形里（1 个输入自由度），连杆组再把小幅摆动放大/整形成末端轨迹。 整机 1 自由度、开环、每循环精确重复——高速自动机（纺织、包装）的心脏。 代价：廓形加工贵、磨损即失真、动载荷大时噪音明显。

优点

  • 运动规律几乎任意设计
  • 结构紧凑（凸轮+几根杆）
  • 开环高速稳定，每循环重复

缺点

  • 凸轮加工成本高
  • 磨损后轨迹漂移
  • 动载荷大时噪音明显

适用

  • 纺织机械（开口、引纬）
  • 缝纫机针杆
  • 包装机封口成型
Delta 的诀窍：平行四边形 → 纯平动
3 组臂各含一个平行四边形，约束掉动平台的全部转动自由度——末端只平动、不旋转（3 DOF：x/y/z）。 所有电机装在静平台上，动质量极小 → 加速度可达数十 g，是"高速拾放"之王（药品、食品分拣 100+ 次/分钟）。 代价：工作空间/占地面积比小，且不能调末端姿态。

优点

  • 电机都在静平台 → 惯性小
  • 加速度极高（数十 g）
  • 结构对称，各向性能均匀

缺点

  • 工作空间/占地比小
  • 纯平动（无姿态自由度）
  • 3 电机需精密协同

适用

  • 高速拾放（药品/食品）
  • 电子元件分拣
  • 并联 3D 打印机
7.1

轨迹设计方法论：想要一条曲线，怎么反求机构？

从"看懂动画"到"设计得出"——四把工具：图谱、频比、同源、数值综合

连杆曲线：单自由度也藏着一整本"曲线字典"
四杆机构连杆（coupler）上任意一点画出的轨迹叫连杆曲线（coupler curve）—— 它是六阶代数曲线，形态覆盖香蕉形、卵形、双环、带尖点、带自交…… 同一个机构，连杆点从曲柄端挪到摇杆端，曲线就完全变样。
设计含义（倒着用）：想要一条曲线，可以先问"它像哪种连杆曲线"—— 翻图谱找到形似的机构与杆长比，缩放到实际尺寸，就是一个单电机解。 纸上时代的工程师真的用整本《连杆曲线图谱（Atlas of Coupler Curves）》干这事。 下面这张九宫格，就是图谱的一页缩影：

连杆曲线图谱九宫格（3 种杆长比 × 3 个连杆点位置）

每格 = 一个四杆机构（灰杆机架、绿杆曲柄、橙点=连杆点）。行：连杆点从靠近曲柄端（上）到靠近摇杆端（下）； 列：连杆长度比例从小到大。看规律：靠曲柄端的点画小圈，中间点画香蕉/卵形，靠摇杆端画大弧。
频比法：五杆轨迹的设计步骤
回到本页 hero 的五杆。它的轨迹由 ω₁:ω₂ 频比 + 相位差 φ + 杆长三组旋钮决定，设计就按这个顺序拧：
  1. ① 定频比要几个瓣/几拍闭合 → ω₁:ω₂ = m:n 整数比（闭合周期 = 最小公倍数拍；非整数比永不闭合）
  2. ② 定相位φ 是"形状旋钮"：同相拉长、正交（90°）圆润——拖 hero 动画的 φ 滑块体会
  3. ③ 定杆长两摇杆 a₁、a₂ 定幅值（工作区域大小）；机架定宽度
  4. ④ 定连杆比b₁、b₂ 与 C 点在连杆上的位置决定曲线细节
  5. ⑤ 全周期采样验证数值跑一圈：装配失败 = 连杆不够长，加长 b 直到 0 失败
为什么整数比才闭合（Lissajous 原理）
C 点是两个圆周运动的"合成"——和示波器上的李萨如图形（Lissajous figure）同构： 频比 m:n 的两个正弦合成，只有当 m、n 都是整数（且约到最简）时，曲线才在最小公倍数个周期后回到起点闭合； 无理数比（如 ω₁:ω₂ = 1:√2）的曲线永远不闭合，逐渐"涂满"一块区域。 ω₁ = ω₂ 时更特殊：五杆变成一个刚性形状在摆动（两输入锁死成一个自由度）——这就是 hero 动画里"同步 → 退化"的含义。
Roberts-Chebyshev 定理：一条曲线，三个机构
同一条连杆曲线，可以由三个不同的四杆机构生成（它们互称"同源机构"，cognate linkages）。 这不是巧合而是定理（Roberts-Chebyshev）：四杆 ABCD 的连杆点 P 的曲线， 通过平行四边形+相似三角形构造，能找出另外两个四杆，其连杆点走出完全相同的曲线。
设计含义（这是它真正值钱的地方）： ① 这个四杆的传动角不好（μmin 太小、传力差）？换成它的同源机构——曲线不变、传动角变好； ② 机构跟障碍/机架干涉？换同源布局绕开。曲线是需求，机构是可选的实现——同源定理给了三个免费备选。

同源机构示意：两个不同的四杆，走出同一条曲线

示意画法：原机构（实线）与一个同源骨架（虚线）共享同一条黑色连杆曲线。 严格构造需要两组平行四边形+相似三角形（机构学教材有完整图解）——这里展示"曲线相同、机构不同"的事实本身。

目标函数：min RMS(b₁, b₂, a₁, a₂, ω, φ)——对每个目标点取曲线上最近距离、求均方根。 你拖滑块是在人肉做梯度下降；工程上让计算机批量试参数（遗传算法、粒子群、梯度法）， 一次搜索几千组杆长组合，附上约束（杆长范围、无装配失败、传动角下限）自动出解。 方法论的完整链条：图谱法（人工查表，快而粗）→ 频比法（五杆，结构化设计）→ 数值综合（任意点列，交给机器）。
我们用串联臂还是并联？ 比赛机器人走了第三条路：3-DOF 串联臂 + 示教走点——轨迹不复杂、速度要求不高时， "多自由度 + 数字控制"最灵活。但若要做工业鸡蛋分拣线（每分钟上百颗）， Delta 并联或凸轮连杆自动机才是正解——速度和节奏决定机构形态。
7.5

驱动与安装

多自由度机构的电机布置有自己的讲究

驱动与安装 · 轨迹机构

五杆：双电机怎么摆

两台电机同基座对置装在机架两端，两曲柄轴线尽量同高、间距 = 机架长—— 电机都不做悬臂负载，轴承受力好；双电机座一次钻孔定两轴孔（中心距就是机架，孔偏 = 机架偏）。

Delta：三电机上静平台

三台电机均布 120° 装在顶部静平台——动质量只剩三根细臂， 这就是它能到数十 g 加速度的全部秘密。电机离末端越远，惯量越小。

六杆/凸轮连杆：单电机直驱

都是 1 自由度——输入轴（曲柄轴/凸轮轴）= 电机轴，法兰直装或联轴器， 与间歇机构页同款逻辑。高速时同步带隔离振动。

实物制作

杆越多，铰链精度越要命

实物制作 · 轨迹机构

五杆有 5 个转动副——每个铰 0.1 mm 间隙，末端累计漂移可达 0.5 mm 级（间隙不抵消、走最坏叠加）。 六杆 7 个铰更甚。轨迹精度 = 铰链精度，全铜套化是底线（见右链）。 Delta 的球铰/万向节用鱼眼轴承成品（M3/M4 杆端关节轴承）， 或打印 TPU 弹性铰（柔顺机构思路：免润滑免间隙，但行程小、会疲劳）。

转动副规范 → 底盘与悬挂 · 铰接设计（铜套）
