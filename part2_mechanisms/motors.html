电机原理 Motors

为什么通上电就会转？三种电机给出三种答案——这一页拆开看。 有刷直流：靠机械换向器（commutator，两个半环 + 电刷）自己翻转电流方向； 步进：靠脉冲通电序列一格一格吸着转子走； 无刷 BLDC：把换向器搬进电子驱动器，用霍尔传感器决定何时切换电流。 看懂这三个"换向"，电机选型就通了。

有刷直流 步进 BLDC 六步换向 舵机

有刷直流电机 · 单匝线圈 + 换向器 + 电刷（轴向剖视）

两个核心公式：安培力 与 反电动势
F = B·I·L（左手定则）　　E = k·ω
F = B·I·L：通电导体在磁场中受力，B 是磁感应强度、I 是电流、L 是导体有效长度。 判断方向用左手定则——磁感线穿入手心，四指指向电流，拇指即为受力方向。 线圈两边电流相反 → 两边受力一上一下 → 形成转矩。
E = k·ω：线圈转起来后自己切割磁感线，产生反电动势（back-EMF），方向与电源电压相反。 转速越高反电动势越大，电流 I = (U − E)/R 越小——所以直流电机的转速有上限， 这也是它能用 PWM 改变电压来调速的物理根源。

机械设计

  • 电刷磨损 = 寿命瓶颈：碳刷与换向器持续摩擦，千余小时后需更换
  • 换向瞬间有火花 → 电磁干扰（EMI），干扰编码器/单片机信号线
  • 换向器占掉转子空间，散热差，堵转易烧线圈

机械制造

  • 成品即用：两根线接上就转，无需驱动器调参
  • 调速 = PWM 改平均电压；换向 = H 桥或双刀双掷开关
  • 比赛里是驱动轮、履带底盘的主力：便宜、扭矩随叫随到

优点

  • 结构最简单，两根线，成本最低
  • 低速扭矩大、响应快（堵转也有力）
  • PWM 调速 + H 桥换向，方案极其成熟

缺点

  • 电刷磨损 → 寿命与可靠性瓶颈
  • 换向火花 → 干扰 + 换向器氧化
  • 本身不知道转没转、转多快，需外加编码器

ASABE 比赛适用

  • 底盘驱动轮、履带行走（配减速箱）
  • 对寿命不敏感的短时重载任务
  • 要位置控制时 → 加编码器闭环（见对比总结）

两相混合式步进 · 八拍通电序列（A⁺→A⁺B⁺→B⁺→B⁻A⁺→B⁻→A⁻B⁻→A⁻→A⁺B⁻ 循环）

当前拍： A⁺ A⁺ A⁻ B⁺ B⁻

掉步演示 · 负载 > 保持扭矩时，转子跟不上（红色偏差角累计）

步距角：一格到底多大
步距角 = 360° / (相数 × 拍数)
两相电机四拍（A⁺→B⁺→A⁻→B⁻）：360°/(2×4) = 90°——这是本页动画用的教学模型； 八拍（半步）再减半。
常见的 1.8° 步进电机为什么这么小？因为真实转子是50 齿的齿槽结构（混合式）， 磁路齿数代替了"极数"：360°/(50×2×整步拍) = 1.8°。齿越多，一格越细。

机械设计

  • 保持扭矩（holding torque）是关键参数：负载超过它就掉步
  • 矩频特性：转速越高扭矩越小，高速场景别选步进
  • 开环省了编码器，但误差无告警——留 50% 扭矩裕度

机械制造

  • 配步进驱动器（A4988/TMC 系列）：单片机给脉冲+方向即可
  • 自带丝杆/导程的直线步进 = 最便宜的直线轴方案
  • 调好细分（microstepping）后低速很安静

优点

  • 开环位置控制：发多少脉冲走多少角，不用编码器
  • 低速可直驱、保持力矩大（断电仍自锁）
  • 成本低、控制代码简单

缺点

  • 掉步无告警：撞了、超载了控制器都不知道
  • 高速扭矩骤降，不适合高速任务
  • 有共振点，某些转速下振动噪音明显

ASABE 比赛适用

  • Z 轴升降、播种/夹取等低速点动轴
  • 节奏简单、负载可预期的执行机构
  • 要求可靠可验证的轴 → 换 BLDC/伺服闭环

三相 BLDC · 星形绕组 + 3 个霍尔传感器 + 六步换向（旋转磁场矢量拉着转子走）

梯形换向（六步）vs 正弦 FOC
每 60° 电角切换一次导通相：U⁺V⁻ → U⁺W⁻ → V⁺W⁻ → V⁺U⁻ → W⁺U⁻ → W⁺V⁻
六步换向（梯形/trapezoidal）：任意时刻只有两相导通（一进一出），磁场矢量每 60° 跳一格—— 结构简单，只需 3 个霍尔传感器（Hall sensor）告诉驱动器"转子到哪了"。转矩有轻微纹波（看下面的梯形波）。
正弦 FOC（磁场定向控制）：三相电流按正弦连续变化，磁场矢量平滑旋转，转矩更平顺、效率更高， 但需要电流采样和复杂算法。比赛用的空心杯/云台 BLDC 多为六步，高性能舵机/机械臂用 FOC。
无电刷 = 无火花、无磨损 → 寿命只受轴承限制；但必须有电子驱动器，三根线接反只反转不损坏。

机械设计

  • 看三个参数：KV 值（转速/伏）、额定扭矩、峰值电流
  • 配行星/谐波减速箱 = 大扭矩低转速关节
  • 过载能力远强于步进：短时 2~3 倍扭矩不烧

机械制造

  • 必须配电调（ESC）/ BLDC 驱动器：信号线给 PWM 或指令
  • 云台电机（低速大扭矩直驱）+ 驱动板 = 关节单元
  • 要位置控制时加编码器 → 就是"伺服"

优点

  • 无电刷 → 寿命长、无火花、无 EMI
  • 功率密度高：同重量下扭矩/转速都占优
  • 效率高（85%+），电池机器人的好朋友

缺点

  • 必须配驱动器，接线多（3 相 + 3 霍尔）
  • 开环通电只会抖不转，天生需要"感知+换向"
  • 低成本驱动器低速有纹波、噪音

ASABE 比赛适用

  • 行走底盘（配减速 + 编码器闭环）
  • 需要长时间高可靠运行的机构主轴
  • 机械臂关节（云台电机 + FOC 驱动板）

一句话选型
要角度（转到这里就停）→ 舵机：三根线，给 PWM 角度即到，大一最容易上手的"角度执行器"；
要转速 + 闭环（轮子、底盘、高速可靠）→ BLDC 或 直流 + 编码器：前者寿命长功率大，后者便宜方案成熟；
省事低速（升降、点动、负载可预期）→ 步进：发脉冲就走，不用调 PID，留够 50% 扭矩裕度防掉步。
