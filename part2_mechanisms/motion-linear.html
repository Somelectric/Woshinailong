第 02 页 · 运动转换 ≈ 30 min 前置：01 自由度

旋转 → 直线 Linear Motion

什么时候需要这种运动？ 末端要沿一条直线往复运动（推、拉、夹、压）。 看似简单，但实现方式五花八门——曲柄滑块、丝杆、齿条、同步带、气缸， 选哪种取决于行程、精度、负载、动力源。这一页五种全动画演示，并给你横向对比和设计流程。

选型结论：要精度和推力选丝杆（分辨率=导程/3200，自锁防掉落）； 要无限长行程选齿条；要安静快速选同步带；只要"推出去-收回来"的二位置粗暴动作选曲柄滑块； 已有气源、要快切二位置选气缸。

  1. 需求行程 H=120 mm、推力 50 N、精度 ±0.5 mm
  2. 选型±0.5 mm → 丝杆（曲柄滑块/同步带达不到）
  3. 定导程分辨率 = 导程/(200×16 细分) → T8 丝杆 = 8/3200 = 0.0025 mm/步 ✓
  4. 校核推力F = 2πηT/导程 → 42 步进 45 N·cm 经 T8 ≈ 56 N ✓
曲柄滑块 = 四杆的"摇杆拉直"
行程 H ≈ 2a　·　x(θ) = a·cosθ + √(b² − (a·sinθ + e)²)
把四杆的摇杆换成滑块（转动副 → 移动副），末端就从摆动变成直线往复。 行程近似 = 2 倍曲柄长（偏置 e 会引入不对称）； 连杆越长，滑块运动越接近标准正弦——越短则"中点快、两端慢"的畸变越明显。 把 e 滑块拉离 0 试试：往复两个半程的时间不再相等（这正是"急回"在滑块机构里的表现）。
对比丝杆：为什么还会选它——曲柄滑块不用丝杆和导轨，一个电机 + 两根杆就能做直线往复； 精度差（杆长误差与铰链间隙直接吃掉重复精度），但速度快、结构极简、不需要任何精密件， 适合"推出去-收回来"的二位置粗暴场景（冲床、推料）。
偏置曲柄滑块的急回
e = 0 时机构对称，去程回程时间相等；e ≠ 0 时滑块极限位置对应的曲柄角不再相差 180°—— 一个方向走得快、另一个方向走得慢。冲床利用它：慢行程压切（力大可控），快行程返回（省时）。 判定框实时显示当前偏置下的行程与急回比。

优点

  • 结构最简单：一个曲柄 + 连杆 + 滑块
  • 把电机的连续转动直接变成直线往复
  • 发动机活塞、冲床、压缩机都用它

缺点

  • 滑块速度不均匀（正弦近似），快速端慢、中点快
  • 行程受限于曲柄长度的 2 倍
  • 侧向力大（无偏置时仍然有侧推）

适用场景

  • 周期性、固定行程的直线往复
  • 动力源是连续转动电机
  • 不要求中间位置精确停位
丝杆的"分辨率"——一步走多远
分辨率 = L / (步数 × 细分) = 8 / (200 × 16) = 0.0025 mm
旋转 → 直线的转换比由导程 L 一个参数决定：电机转一圈，螺母恰好走一个导程—— 纯几何关系、无滑差。俱乐部 3D 打印机的经典配置：导程 8 mm 丝杆 + 1.8° 步进（200 步/转）+ 16 细分 → 每步 0.0025 mm。这就是为什么丝杆是"精密直线"的代名词——降速比大到不需要齿轮。 代价：速度慢（要 1 m/min 就得让丝杆以 125 rpm 高速旋转，还受临界转速限制）。 把导程滑到 2 mm 试试：同样一圈电机，滑台只走 1/4——慢而精。
为什么俱乐部首选它：精度、推力、断电自锁（小导程螺旋角小于摩擦角）三项全占； 缺的只是速度——而比赛直线动作（升降、夹爪开合）恰恰不需要快。

机械设计

  • 导程小 → 慢而精：分辨率高，且同样电机扭矩下推力更大（F ∝ T/L）
  • 梯形丝杆（T8）能自锁：断电不坠落；滚珠丝杆效率高（>90%）但不自锁
  • 长行程要校核临界转速（甩振）与丝杆下垂

机械制造

  • 丝杆光杆买成品（T8 丝杆 + 黄铜螺母，几块钱一套）
  • 螺母座 / 滑台 3D 打印；孔位按光杆与导轨实测尺寸留 0.2 mm 余量
  • 俱乐部 3D 打印机的 Z 轴就是它——拆一台对照上图看

优点

  • 精度高（微米级）
  • 减速比大（导程小则更慢）
  • 能自锁（梯形螺纹）

缺点

  • 速度慢
  • 滚珠丝杆成本高
  • 长行程时丝杆下垂

适用

  • 3D 打印机、CNC
  • 精密定位台
  • 升降柱

齿轮齿条的传动关系
v齿条 = ω · r = π·m·z·n / 60　　每转位移 = π·m·z = 节圆周长
齿轮转一圈，齿条走一个节圆周长——和卷尺拉开同一个道理，且齿与齿槽啮合， 理论上零滑差。齿数 z 越多，同转速下齿条走得越快（r = mz/2 变大）， 但同样电机扭矩下推力越小（F = T/r）。动画里红点是轮齿上的标记，绿点是齿条上的标记—— 两者始终同步前移，这就是"无滑差"的可视化验证。

机械设计

  • 行程无限：齿条接多长走多长，这是丝杆做不到的
  • 效率高（~95%）；F = T/r，小齿轮 = 大推力（液压转向都用小齿轮）
  • 有齿隙 → 回程误差；重载要加消隙机构（双片齿条预紧）

机械制造

  • 小齿轮买成品（模数 1~2，内孔配电机轴 D 形或键槽）
  • 齿条可激光切割或打印——务必按同模数生成齿形，节距对不上会顶齿
  • 安装时调中心距：留 0.1~0.2 mm 侧隙，既能转又不旷

优点

  • 传动效率高
  • 行程理论上无限
  • 结构紧凑

缺点

  • 有齿隙（影响精度）
  • 需要润滑
  • 高速时噪音大

适用

  • 汽车转向
  • 大型数控机床
  • 铁路道岔
同步带的传动关系
v带 = ω1·r1 = ω2·r2　　n2 = n1·z1/z2
带是同一根，所以两轮边缘线速度必然相等——这就是带传动的"合同"。 同步带内壁有齿，与轮槽啮合，无滑差（平皮带会打滑）。 两轮转向相同（带绕外圈），这是它与齿轮副（转向相反）的关键区别。 红色标记点随带走一圈，注意上下两段带移动方向相反。

机械设计

  • 远距离传动首选：中心距几米都行（齿轮做不到）
  • 同步带无滑差、无齿隙，精度介于丝杆与平皮带之间
  • 高速轻载；大扭矩会跳齿

机械制造

  • GT2 皮带轮 + 皮带全部买成品（3D 打印机同款，便宜量足）
  • 张紧机构必备：长孔 + 螺钉调中心距，或加惰轮张紧
  • 皮带按行程裁长度、接头用同步带扣——比赛队直接买环形带

优点

  • 远距离传动效率高
  • 无齿隙（同步带）
  • 噪音低、无需润滑

缺点

  • 长期会松弛
  • 高速可能跳齿
  • 精度不如丝杆

适用

  • 3D 打印机 X/Y 轴
  • 白板笔机器人
  • 自动门
气缸的输出力
F = p · A = p · πD²/4　　伸出更快更猛（有杆腔面积小）
气缸把"压强 × 面积"直接变成直线力——不需要任何中间传动。 0.5 MPa（5 bar）+ 32 mm 缸径 → F ≈ 400 N，比舵机大一个量级。 双作用缸两个口交替进排气：左口进气伸出、右口进气缩回； 两端的磁感应限位开关给控制器"到位"信号（这就是它的"反馈"）。 气缸只有"伸出/缩回"两个稳定位置，中间停不住——要中间停请用上面三个电动方案。

机械设计

  • 两位置快速切换的最简方案：到位由限位开关告知
  • 力 = 压强 × 面积：缸径翻倍力翻 4 倍；伸出/缩回速度不同（有杆腔面积小）
  • 冲击大：末端加速度可达数十 g，抓易碎品要靠气路节流阀缓冲

机械制造

  • 全买成品：SMC / 亚德客气缸几十一百元，自带限位磁环
  • 系统四件套：气泵 + 电磁阀 + 气管 + 节流阀（电磁阀决定换向时序）
  • 气路快插接头免加工；只有安装支架需要自己打印

优点

  • 直接出直线运动，最简单
  • 响应快（气动）
  • 力大（液压）

缺点

  • 气动只能两位置（无法中间停）
  • 需要气源/液压站
  • 电动推杆自锁看型号

适用

  • 夹爪开闭
  • 推料、顶出
  • 二位置切换

驱动与安装

电机放哪、怎么传、怎么固定——五种方案各不同

驱动与安装 · 直线机构

电机放哪

丝杆：电机与丝杆同轴直联（联轴器），远端加轴承座——悬臂是丝杆下垂与抖动的主因。 齿条：电机装在滑座上随动，小齿轮装电机轴。同步带：电机座在带轮端。 曲柄滑块：电机轴与曲柄销同轴直驱。气缸：无电机（电磁阀控制气路）。

直驱还是传动

丝杆本身就是"旋转→直线"的减速器（导程小 = 减速比大），一般不再外加减速； 齿条/同步带通常电机直驱小齿轮/带轮（它们没有减速效应，需要时再加行星减速箱）。

电机座怎么做

打印 L 形电机座，42 步进按 31 mm 孔距 标准孔（建议做成 CAD 库文件）； 轴承座孔比轴承外径 +0.1；同步带电机座留长孔调中心距张紧。

实物制作

移动副（导轨滑块）+ 转动副（曲柄铰）

实物制作 · 直线机构

移动副（直线导轨）两种做法：① 光轴 Ø8 + 直线轴承 LM8UU（标准件最顺滑，滑台打印机同款）； ② 打印滑块 + 光杆（孔放大 0.2、贴 PTFE 膜减摩——便宜，摩擦大一点）。 平行度是生命线：两根光轴的孔必须在同一块板上一次钻出，分次钻必卡。 丝杆螺母座：打印件留 0.2 余量配 T8 黄铜螺母（加热后压入）。 曲柄滑块的曲柄销是转动副——做法见右侧链接。
