直线运动 Linear Motion

什么时候需要这种运动？ 末端要沿一条直线往复运动（推、拉、夹、压）。 看似简单，但实现方式五花八门，选哪种取决于行程、精度、负载、动力源。

优点

  • 结构最简单：一个曲柄 + 连杆 + 滑块
  • 把电机的连续转动直接变成直线往复
  • 发动机活塞、冲床、压缩机都用它

缺点

  • 滑块速度不均匀（正弦近似），快速端慢、中点快
  • 行程受限于曲柄长度的 2 倍
  • 侧向力大（无偏置时仍然有侧推）

适用场景

  • 周期性、固定行程的直线往复
  • 动力源是连续转动电机
  • 不要求中间位置精确停位

优点

  • 精度高（微米级）
  • 减速比大（导程小则更慢）
  • 能自锁（梯形螺纹）

缺点

  • 速度慢
  • 滚珠丝杆成本高
  • 长行程时丝杆下垂

适用

  • 3D 打印机、CNC
  • 精密定位台
  • 升降柱

优点

  • 传动效率高
  • 行程理论上无限
  • 结构紧凑

缺点

  • 有齿隙（影响精度）
  • 需要润滑
  • 高速时噪音大

适用

  • 汽车转向
  • 大型数控机床
  • 铁路道岔

优点

  • 远距离传动效率高
  • 无齿隙（同步带）
  • 噪音低、无需润滑

缺点

  • 长期会松弛
  • 高速可能跳齿
  • 精度不如丝杆

适用

  • 3D 打印机 X/Y 轴
  • 白板笔机器人
  • 自动门

优点

  • 直接出直线运动，最简单
  • 响应快（气动）
  • 力大（液压）

缺点

  • 气动只能两位置（无法中间停）
  • 需要气源/液压站
  • 电动推杆自锁看型号

适用

  • 夹爪开闭
  • 推料、顶出
  • 二位置切换
在我们的机器人上 末端刮板的扫动其实就是一种简化曲柄滑块——舵机驱动刮板绕一个轴摆动，把鸡蛋扫入收集筐。 如果刮板要做长行程直线运动（而不是摆动），可以考虑改成齿条或同步带方案。
