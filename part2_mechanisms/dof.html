自由度 Degrees of Freedom

为什么要先讲自由度？ 它是判断一个机构"能不能动"和"怎么动"的基本工具。 机构设计的第一个问题永远是：这个机构有几个自由度？需要几个原动件？

平面机构自由度公式

F = 3n − 2PL − PH
n · 活动构件数
不含机架
PL · 低副数
转动副、移动副（面接触）
PH · 高副数
齿轮副、凸轮副（点/线接触）

交互计算器 · 试试看

当前机构的自由度
3
F = 3n − 2PL − PH
= 3 × 3 − 2 × 3 − 0 = 3
F = 3：需要 3 个原动件才能确定运动。这是典型串联机械臂的配置——每个关节配一个电机。

F = 0

  • 结构，不是机构
  • 没有可动件，受载荷而不动
  • 例子：桁架、桥梁

F = 1

  • 最常见——单原动件机构
  • 一个电机/舵机驱动，运动规律完全确定
  • 例子：四杆、凸轮、齿轮系

F ≥ 2

  • 多自由度机构
  • 需要多个原动件协同
  • 例子：串联机械臂（F=DOF 数）

F < 0

  • 超约束
  • 装配时需要变形才能装上
  • 例子：双联轴承（设计需谨慎）
在我们的机器人上 3-DOF 机械臂：3 个活动构件 + 3 个转动副，F = 3×3 − 2×3 − 0 = 3。 这就是为什么我们需要 3 个舵机来控制它——每个自由度对应一个独立电机。
