选型结论：低速、要可编程、省事 → 舵机（自带电机+减速+闭环，比赛默认）； 高频循环（>2Hz）→ 四杆（一个匀速电机顶舵机的抖动与电流尖峰）； 要"停歇+特定规律" → 凸轮（代价是廓形加工）；大摆角大负载 → 齿条-齿轮。

  1. 需求输出摆角 ψ=60°、急回 K=1.2
  2. 两位置综合给定机架 d、摇杆 c，作图定曲柄 a 与连杆 b
  3. Grashof 校验a+b ≤ c+d（最短+最长 ≤ 其余两和）保证曲柄整转

优点

  • 纯转动副，磨损小、寿命长
  • 设计成熟，杆长变了运动规律就变，灵活度高
  • 能精确控制末端的摆角范围与节奏
  • 刚性好，能承受较大载荷

缺点

  • 需要满足 Grashof 条件才有曲柄
  • 运动到"死点"会卡死（需要飞轮或对称布置）
  • 杆长一旦定死，运动规律不可调

适用场景

  • 需要周期性摆动的释放/分拣机构
  • 机械臂肩/肘关节（多用多组四杆串联）
  • 履带悬挂、悬挂系统
  • 压力机、剪切机
推导 · 曲柄为什么存在？Grashof 条件的三式证明（浙大 朱秋国老师讲义）

设四杆 a（曲柄）、b（连杆）、c（摇杆）、d（机架）。若 a 能整周回转，必有两次与机架共线—— 一次折叠共线、一次拉伸共线。这两次机构都必须仍能装配（三角形两边之和 ≥ 第三边）：

拉直（B、D 最远）：a + b ≤ c + d …且 a + c ≤ b + d …且 a + d ≤ b + c
折叠（B、D 最近）：b ≤ (d − a) + c …等三式

三式两两相加，全部消去公共项，得到唯一幸存的条件族：

a ≤ b，a ≤ c，a ≤ d —— 曲柄是最短杆，且 s + l ≤ p + q（Grashof 条件）

再按最短杆的身份分类：最短杆为连架杆 → 曲柄摇杆；为机架 → 双曲柄；为连杆 → 双摇杆。 这就是判定框里那行结论的完整来历——判定不是背口诀，是三角形不等式。

传动角 μ · 这个机构"传力顺不顺"
cos μ = (b² + c² − BD²) / (2bc)　（μ 取锐角）
连杆推摇杆的力沿连杆方向，但只有沿摇杆垂直方向的分量才真正做功—— 分量比例就是 sin μ。μ = 90° 传力最顺；μmin < 40° 时机构效率骤降甚至自卡。 μmin 出现在曲柄与机架共线的两个位置（θ₁ = 0° 和 180°），判定框实时监控—— 调滑块试试把 μmin 压到 40° 以下，看警告变色。
为什么不用舵机就好：舵机最简单，但高频循环（>2 Hz）时舵机抖动、电流尖峰大、还可能过热—— 四杆让一个匀速电机干所有活，缝纫机不需要舵机。反过来，低速、要可编程、负载小 → 舵机完胜（见 3.1 表）。
死点 · 急回 —— 四杆的两个"脾气"
死点：若改由摇杆驱动（曲柄作从动），当连杆与曲柄共线时（传动角 μ → 0°）， 无论多大的力都推不动曲柄——机构"锁死"。对策：飞轮储能冲过死点、双机构错相布置、或干脆电机直驱曲柄侧。
急回：摇杆两极限位置对应曲柄两角度不等（差 = 极位夹角 θ），往复行程曲柄转角不同 → 回程更快。K = (180°+θ)/(180°−θ)，把 K 设计大，机器"干活慢、退回快"，省节拍时间—— 牛头刨床、颚式破碎机都吃这个红利。
在我们的机器人上 好蛋释放机构 = 简化版铰链四杆：侧置舵机驱动铰链板绕固定轴旋转。 注意它只是"单臂铰链"——只有一个转动副+板本身作为连杆，是最简单的四杆退化情形。 想象再加一根连杆让舵机远离铰链点，就是标准曲柄摇杆了。
压力角 α · 凸轮的"推力方向"问题
tan α = |ds/dφ| / (r₀ + s)
凸轮推从动件的力沿接触点法线方向，只有沿导路方向的分量在干活—— 分量比例 = cos α。α 太大（> 30°）时侧向分力剧增，导路摩擦卡死（自锁风险）。 从公式看：减小 h、放慢升程（β ↑）、增大基圆 r₀ 都能压 α—— 把 r₀ 滑块拉大试试，读数里 α 应明显下降；代价是整个凸轮变大变重。 "性能换体积"，这是机构设计最典型的权衡。
凸轮 vs 四杆：要"停歇 + 特定运动规律"（比如吸气门停顿等待）凸轮是唯一解—— 廓形把整条 s(φ) 曲线刻进几何。但廓形必须精加工（CNC/慢走丝）； 俱乐部激光切割亚克力凸轮精度 ±0.1 mm，只够低速演示，比赛频繁循环会磨损漂移。

优点

  • 廓形任意设计 → 摆杆运动规律（含停歇）几乎任意
  • 能精确实现"升—停—回—停"的节奏
  • 结构紧凑，一个凸轮就能驱动复杂摆动

缺点

  • 点/线接触，磨损快、需润滑
  • 廓形加工精度要求高（误差直接变运动误差）
  • 回程靠弹簧/重力，高速可能跳脱（力封闭）

适用场景

  • 发动机配气（凸轮轴开合气门）
  • 自动机械的"时序"动作（缝纫机、包装机）
  • 需要中途停歇的摆动

优点

  • 最简单：舵机直接输出有限角度，无需连杆设计
  • 角度可程序控制，能随时停在任意位置并保持
  • 位置闭环（内置电位器），定位准、重复性好

缺点

  • 摆角有限（常见 180°/270°），不能连续转
  • 扭矩有限，大负载要选大舵机或加减速齿轮
  • 掉电会松（除非用带制动/自锁的型号）

适用场景

  • 有限角度的开关、翻板、释放
  • 机械臂肩/肘/腕关节（多舵机串联）
  • 我们的好蛋释放铰链板就是这种

优点

  • 齿条往复 → 齿轮有限摆动，转换直接、刚性好
  • 传动比 = 1/r，齿轮越小同样行程摆角越大
  • 啮合传动可靠，可传递较大扭矩

缺点

  • 有齿隙（回程误差）
  • 需要润滑，高速有噪音
  • 齿条行程限制了最大摆角

适用场景

  • 汽车转向器（齿轮齿条式）
  • 需要大扭矩有限摆动的场合
  • 直线执行器（气缸/丝杆）→ 旋转摆动

驱动与安装

驱动点选在哪根杆上，是有讲究的

驱动与安装 · 摆动机构

电机放哪

四杆：电机直驱曲柄轴——曲柄是唯一整转杆，驱动点必须在这（驱摇杆会死点锁死）。 凸轮：电机与凸轮同轴直驱（凸轮轴就是输入轴，两端轴承座——悬臂凸轮会啃从动杆）。 舵机：本身就是执行器，耳片朝下装在掌基/舵机座上，输出臂直接连摆杆。

直驱还是传动

四杆/凸轮转速高时，电机先经同步带减速再进（隔离振动与冲击反扭矩）； 比赛低速场景步进/减速直流直驱即可。舵机不需要任何外传动——它就是"电机+减速+闭环"三合一。

电机座怎么做

打印舵机座用标准耳片孔位（MG996R 49.5×10.1，建议做 CAD 库文件）； 凸轮轴两端各一个轴承座；四杆曲柄轴电机座与机架铰孔同板一次钻出（同轴度）。

实物制作

转动副是四杆的生命线——间隙就是回差与振动

实物制作 · 转动副（摆动机构的命脉）

铰链间隙直接吃掉摆动精度：每个铰 0.1 mm 间隙，四杆末端就能漂 0.4 mm+。 打印一体铰链是新手大坑——层间强度低、摩擦大、间隙不可控。 永远用螺丝作轴 + 铜套作轴承 + 防松螺母埋六角坑的标准做法。 舵机路线则免掉这一切：输出臂与摆杆的连接用一颗 M3 自攻 + 舵机原装圆盘。
