夹持 & 拾取 Gripping

末端要"抓住—移动—放开"目标物，但抓取从来不是"装个夹爪"这么简单。 三个核心问题：抓什么形状？需要多大夹持力？会不会伤到对象？ 本页先用一张对比表把连杆夹爪 / 真空吸盘 / 柔顺软爪 / 刮板四条路线按对象要求、力控方式、对定位误差的容忍度排开， 再逐个算清楚——包括那道著名的"夹一颗 42 g 鸡蛋需要 0.7 N"的例题，和它背后"不夹"的设计决策。

怎么读这张表：对象形状规则、表面硬（方块零件、苹果、土豆）→ 连杆平行夹爪，力可控、位置误差容忍中等； 对象表面光滑不透气（玻璃、光滑水果）→ 真空吸盘，速度最快，但蛋壳有细微纹理会漏气——这是本队比赛实测教训（页内例题算过：理论吸力 35 N，实际败在密封）； 对象异形又怕伤（草莓、蘑菇）→ 柔顺软爪，弹性结构自己限力；散料批量、不追求单颗姿态 → 刮板最快最省，但它和比赛策略耦合（要"识别"就接称重，见最后 tab）。 电磁一栏未入表——比赛用塑料蛋，非铁磁直接出局，页内仅作对照。
例题

夹爪设计四步：从对象特性到指面材料

需求：夹取鸡蛋，单颗 42 g，夹持力 ≤1 N 防碎（蛋壳集中应力会压裂）。

  1. 对象定原理表面粗糙 + 怕碎 + 曲面 → 排除吸盘（漏气）→ 连杆平行夹爪 + 软垫，靠摩擦托住而不是夹紧
  2. 反推舵机摩擦自锁条件 N ≥ mg/2μ ≈ 0.7 N；再用页内 F = T/|dx/dθ| 链路反推舵机规格——连杆式"越夹越紧"，力从不是瓶颈
  3. 定行程张开量 = 对象直径 + 余量 10 mm（补视觉定位误差）→ 由 2(l−r)~2(l+r) 反解曲柄销半径 r 与连杆长 l
  4. 指面材料指板贴 海绵 / EVA 垫：把集中应力摊成面接触，同时增大摩擦系数 μ——材料选择就是最便宜的"力控"
夹持力从哪来 · 虚功原理
F = T / |dx/dθ|
T 是舵机扭矩，dx/dθ 是手指位移对曲柄角的导数（机械增益的倒数）。 连杆接近"闭合死点"时 |dx/dθ| → 0，力被急剧放大——这就是连杆式夹爪"越夹越紧"的原理， 也是它夹易碎品时要靠电流限制或柔性垫来保护对象的原因。
为什么是它 vs 其他：吸盘的"力"由真空度和直径平方决定，不可微调且依赖密封；软爪的力被弹性上限锁死但不可放大，抓不住重物； 只有连杆夹爪的夹持力是设计变量——连杆比（r、l）就是你的力放大器旋钮，堵转力可以从几牛调到几百牛。代价是要防"过劲"：闭合死点附近必须靠软垫或电流限幅兜底，这正是它对易碎品不如软爪省心的地方。
例题 · 夹住一颗 42 g 的鸡蛋，到底需要多大的夹持力？

两指对夹时，鸡蛋靠摩擦力被托住。每指压力 N 产生摩擦 μN，两指共 2μN ≥ mg：

N ≥ mg / 2μ = 0.042 × 9.81 / (2 × 0.3) ≈ 0.69 N

单指只需 ≈ 0.7 N。而连杆夹爪在夹紧位置能输出几十到几百 N —— 力从来不是瓶颈。

结论：夹鸡蛋的难点不在"夹得住"，而在冲击控制与压力分布（集中应力会压裂蛋壳）。 这正是我们最终改用"刮板扫入 + 称重"的原因之一：根本不夹。

优点

  • 连杆增力：小舵机输出大夹持力
  • 两指平行移动，对象姿态稳定
  • 结构成熟，可 3D 打印自制

缺点

  • 接近闭合时传动角变小，速度慢
  • 开度范围受 r、l 限制（见上方判定）
  • 硬爪夹易碎品需柔性垫 / 力控

适用

  • 规则零件上下料、装配
  • 包装码垛
  • 有一定刚性的农产品（苹果、土豆）
吸盘吸力
F = Δp · A = Δp · πD² / 4
Δp 为真空度（家用微型泵约 40–60 kPa），D 为吸盘有效直径。 吸力与直径平方成正比——想要更大吸力，加直径比加真空度划算。
为什么是它 vs 其他：吸盘是四条路线里唯一响应最快、对表面零压伤的——通断即吸放，没有闭合冲击； 但它的入场券是表面质量：光滑、不透气、曲率平缓，缺一样就漏。连杆夹爪对表面不挑、对形状挑剔；吸盘正相反——对形状宽容（波纹盘贴曲面）、对表面苛刻。 所以"光滑平面批量搬"用吸盘，"什么都可能来一颗"的农业场景它风险最高（本队比赛教训：蛋壳纹理漏气）。
例题 · 30 mm 吸盘能否吸起 42 g 鸡蛋？

F = 50 000 Pa × π × 0.03² / 4 ≈ 35 N

鸡蛋重力仅 0.41 N，垂直吸持裕度 85 倍。但鸡蛋表面有细微纹理、且是曲面—— 实际有效真空度打折，密封性才是真空吸附抓蛋的真正门槛（这也是比赛里多数队伍放弃它的原因）。

理论吸力 ≫ 需求；工程成败取决于密封与表面适应。

优点

  • 对表面无损伤
  • 响应快
  • 曲面/异形面也能适应（波纹吸盘）

缺点

  • 需要气源（泵/真空发生器）
  • 多孔、粗糙表面难密封
  • 断气即失效，需保持压力

农业上最常用

  • 水果采摘（苹果、番茄）
  • 禽蛋分级线（工业）
  • 包装、玻璃搬运
柔顺机构 · 让"材料弹性"代替"控制"
传统思路：传感器 + 力控算法保证不捏碎对象。 柔顺思路：爪本身是弹性的（TPU 打印 / 气动波纹管），接触后自然 conform 到对象形状， 压力被结构本身限制住——不需要任何力反馈。这叫"把控制问题变成结构问题"， 是大一大二就能落地的设计思维（比赛里织物坏蛋仓也是同一思想）。
为什么是它 vs 其他：连杆夹爪要"算准力 + 加软垫 + 怕过劲"，吸盘要"挑表面 + 供气源"，软爪把两头的麻烦都交给材料—— 对形状和定位误差的容忍度是四条路线里最高的（爪自己包过去）。代价是定位精度低、承载力有限：它是"温柔但不壮"， 抓 42 g 的蛋绰绰有余，抓 500 g 的土豆就要重新设计刚度。选型口诀：宁可牺牲精度也不许伤对象 → 软爪。

优点

  • 对形状适应性极强
  • 对易碎品天然友好
  • 无需精确位姿、无需力控

缺点

  • 定位精度低
  • 承载力有限
  • 气动型需要气源

适用

  • 鸡蛋、草莓、蘑菇
  • 不规则零件
  • 食品分拣
为什么"重量"是好蛋/坏蛋的可靠特征
好蛋 ≈ 42 g　·　坏蛋 < 20 g
ASABE 比赛用好实心蛋（~42 g）和坏蛋（<20 g），重量差超过一倍—— 一个薄膜压力传感器 + 一个阈值，就完成了"识别 + 分拣"两个子任务。 把阈值滑到 20~42 之间试试分类正确率；再滑出这个区间，看错误率如何飙升。
为什么是它 vs 其他：夹爪 / 吸盘 / 软爪都只解决"拾取"一个子任务，识别还得另加视觉—— 刮板方案的杀伤力在于与比赛策略耦合：刮板完成收集、称重完成识别，共享"蛋被扫入"这一个物理点，三件事一次做完。 它不精（不保证单颗姿态、要特定方向扫、依赖筐定位），但比赛要的是吞吐量不是姿态美——最快 + 最便宜 + 白送识别，这是其他三条路线给不了的组合。

优点

  • 结构最简单（一个舵机 + 一块板）
  • "拾取 + 识别"一个动作完成
  • 不夹不压，对易碎品冲击可控

缺点

  • 只能从特定方向扫
  • 需要收集筐精确定位
  • 不适合堆叠场景

耦合思维的产物

  • 刮板 = 收集子任务的解
  • 底部传感器 = 分拣子任务的解
  • 共享"蛋被扫入"这一物理点 → 合并

电磁铁 · 优点

  • 响应极快
  • 无机械接触
  • 通断即吸放

缺点

  • 仅铁磁材料（比赛用塑料蛋 → 不可用）
  • 断电即失效
  • 剩磁问题

适用

  • 钢板搬运
  • 铁/非铁分拣
  • 快速夹持切换工装
5.2

驱动与安装 舵机藏于掌基：末端每一克外突都在放大手臂惯量

驱动与安装 · 末端执行器

电机放哪

舵机藏于掌基（手腕处），耳片向下、重心尽量贴近掌面——末端重心外突会放大手臂惯量抖动， 手臂越长这个惩罚越重（惯量 ∝ m·d²）。舵机藏进去还能被掌基罩住，跌落碰撞时首当其冲的不是塑料齿轮箱。

直驱还是传动

舵机输出盘直接驱动主动连杆——舵机本身就是"电机 + 减速 + 闭环"三合一，自带位置反馈； 手指连杆就是传动（力放大 + 行程转换），所以舵机直驱主动杆即可，不再外加齿轮。加一级齿轮只会引入回差与噪音。

电机座（掌基）

3D 打印掌基一体舵机舱：按舵机耳片尺寸留舱（MG996R 耳片 49.5 × 10.1 mm，M3 沉孔）， 舱壁兼作手指导轨的安装面——掌基一次打印同时解决"舵机座 + 导轨 + 手指限位"三个功能。

5.3

实物制作 连杆铰链全部标准化；吸盘路线全买成品

实物制作 · 末端执行器

连杆夹爪的铰链全是短轴转动副：M3 螺丝作轴、铜套/垫片作隔套——隔套防止相邻连杆互相摩擦， 这一点与底盘摆臂铰接是同一套规范。指板激光切割 3 mm 亚克力，软垫 EVA/海绵背面胶粘接。 吸盘路线则完全反过来：真空发生器 + 硅胶吸盘全部买成品（气路接头是标准件），自制件只剩安装支架——把精力留给密封面的贴合设计。

转动副规范 → 底盘与悬挂 · 铰接设计（铜套）
M3 螺丝 + 铜套 + 垫片隔套的标准做法：免调拧紧、面接触不硌坏孔、回差小
连杆铰链M3 螺丝 + 铜套/垫片隔套
指板激光切割亚克力 3 mm
软垫EVA / 海绵（背胶粘接）
掌基3D 打印一体舵机舱
吸盘路线真空发生器 + 硅胶盘（成品）
末端执行器实物（往届赛车） 收集筐 + 刮板 + 底部压力传感器。注意它没有夹爪—— "不夹"本身就是经过计算的设计决策：需要的夹持力只有 0.7 N，但冲击与应力集中才是真正的风险， 而且任务还需要"识别"，刮板方案把三件事一次做完。
选末端执行器先算三笔账：要多大力？会不会伤？能不能和其它子任务耦合？——而不是先问"夹爪长什么样"。
